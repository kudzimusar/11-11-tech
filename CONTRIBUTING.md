# Contributing

11-11 Tech uses `main` as the deployable website branch.

For material changes:

1. Create a focused feature branch.
2. Keep portfolio claims evidence-based.
3. Run `npm run build` before opening a pull request.
4. Verify desktop and mobile layouts.
5. Do not commit secrets or private client information.
6. Keep backend integrations isolated from presentation components.

A public repository does not make the brand assets or code open source; see `LICENSE.md`.
